# Contributors

## Issue reports and testing

- **[@salvadorc17](https://github.com/salvadorc17)** asked for a prebuilt version
  ([#1](https://github.com/sp00nznet/vig8/issues/1)). A build of the game can't be published (it
  contains the recompiled game code), which is why releases now ship the recomp-launcher installer:
  it builds the game on your machine from your own copy, with no tools to set up by hand.
- **[@gabrielrjzx](https://github.com/gabrielrjzx)** asked which ReXGlue version the project builds
  with ([#2](https://github.com/sp00nznet/vig8/issues/2)). It was 0.1.2, pinned nowhere; the README
  now names the exact SDK commit, and `tools/setup.ps1` pins it.
